# 个人 CV / 艺术实践页面模板

这是我自用的页面模板，按照自己的阅读习惯与审美偏好设计：克制的黑白灰、接近纸张的版面、以文字为主的层级，以及展开作品时平缓的位移与吸顶效果。公开这个仓库是为了保存页面结构和交互方式，不表示它是一套通用组件库。

仓库中的姓名、学校、作品、论文和联系方式均为占位示例；我的个人照片、真实作品图片、论文全文、私人资料及原图备份不在这里。示例 SVG 仅用于展示排版。**这个仓库不是我的正式 CV 或作品集。**

## 结构

```text
index.html          页面结构与示例内容
styles.css          排版、响应式样式与打印样式
script.js           展开、切换、吸顶、图片放大等交互
assets/             可替换的 SVG 占位图
papers/sample.html  阅读窗口的示例页面
```

无需构建工具，直接打开 `index.html` 即可预览。修改内容时，从 `index.html` 中对应板块的占位文字入手；图片放入 `assets/` 并更新 `src`。图片建议保留原图备份，并以无损格式制作网页版本。较大的图片使用 `loading="lazy"`；不要把源文件、个人信息或未授权内容提交到公开仓库。

页面仅作为个人模板公开，保留原有署名与权利；仓库未附加开源许可证。
