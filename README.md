# 个人 CV / 艺术实践页面模板

这是我自用的页面模板，按照自己的阅读习惯与审美偏好设计：克制的黑白灰、接近纸张的版面、以文字为主的层级，以及展开作品时平缓的位移与吸顶效果。公开这个仓库是为了保存页面结构和交互方式，不表示它是一套通用组件库。

当前版本同步了我实际页面的最新结构：邮箱与账号位于页眉，姓名和链接与照片并排，个人介绍成为第一个独立栏目；一级标题统一位于灰线下方。正在进行的项目位于技能之前，并与艺术作品共用横排、切换、置顶和收起动画。作品、论文、学校、活动及普通折叠项在全页范围内只保留一个展开状态。

仓库中的姓名、学校、作品、论文和联系方式均为占位示例；我的个人照片、真实作品图片、论文全文、私人资料及原图备份不在这里。示例 SVG 仅用于展示排版。**这个仓库不是我的正式 CV 或作品集。**

## 结构

```text
index.html          页面结构与匿名占位内容
styles.css          三档字号、灰色元数据、响应式与打印样式
script.js           单一展开状态、平滑滚动、双层吸顶、图片放大等交互
assets/             可替换的 SVG 占位图
papers/sample.html  阅读窗口的示例页面
```

无需构建工具，直接打开 `index.html` 即可预览。修改内容时，从 `index.html` 中对应板块的占位文字入手；图片放入 `assets/` 并更新 `src`。图片建议保留原图备份，并制作适合网页显示尺寸的副本。较大的图片使用 `loading="lazy"`；不要把源文件、个人信息或未授权内容提交到公开仓库。

“更多作品”使用嵌套作品导航：外层作品栏和内层作品栏会分别吸顶，脚本会为两层标题预留空间，使展开后的年份、材料和正文不会被遮挡。新增或删除作品时，保持现有 `details`、`summary` 和 `portfolio-*` 类名即可，不需要固定列数。

页面仅作为个人模板公开，保留原有署名与权利；仓库未附加开源许可证。
